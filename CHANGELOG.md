# Changelog

## 1.0 — 2026-09-08

- Added a Windows GUI for selecting artwork, decal ID, game folder, and output folder.
- Automatically creates the large, medium, and small artwork packages.
- Validates dimensions, pixel formats, internal names, native LZO data, and final package hashes.
- Creates a ready-to-share artwork ZIP, manifest, README, and detailed tool log.
- Auto-detects common Steam library locations and allows manual selection.
- Prevents accidental collisions with existing game packages and never writes into the game folder.
